# Twitter Trending Hashtags Fetcher

A Python application that fetches trending hashtags from Twitter/X using their API v2 and displays them with sample tweets.

## Features

- Fetch global trending hashtags
- Fetch trending hashtags for specific locations (using WOEID)
- Search for recent tweets by hashtag
- View available trend locations
- Comprehensive error handling for API issues
- Clean, user-friendly CLI interface

## Prerequisites

1. Twitter Developer Account
2. Twitter API v2 Access with Bearer Token

## Setup

1. Apply for Twitter Developer access at https://developer.twitter.com/
2. Create a new Project and App in the Developer Portal
3. Generate a Bearer Token for your App
