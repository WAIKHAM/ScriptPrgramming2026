# Introduction to Web Scraping

This project introduces web scraping basics using Python `requests` and `BeautifulSoup4`.

## Features
* **HTML Fetching**: Downloads webpage content using `requests`.
* **HTML Parsing**: Parses structured content using `BeautifulSoup4`.
* **Error Handling**: Graceful network error management.

## Setup & Run
1. Activate virtual environment: `venv\Scripts\activate`
2. Install dependencies: `pip install requests beautifulsoup4`
3. Run script: `python main.py`
